# 🧬 DNA Sequence Analyzer

**Developed by Amir Raza | Bioinformatics Project**

A Python-based web application built using Streamlit to analyze DNA sequences.

## About the Project

This project allows users to enter DNA sequences and perform basic sequence analysis using Python.

## Features

- DNA sequence input
- DNA sequence validation
- Sequence length calculation

## Technologies Used

- Python
- Streamlit

## How to Run Locally

1. Clone this repository.
2. Install the required packages:

```bash
pip install -r requirements.txt
```

3. Run the application:

```bash
streamlit run app.py
```
